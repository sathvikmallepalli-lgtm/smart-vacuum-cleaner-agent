From a room to an intelligent agent

◎

Perceive

The agent senses dirt in its cell and checks the four neighbors. It cannot see hidden dirt across the room.

⌁

Decide

If dirty, clean. Otherwise, the memory agent uses BFS on its discovered map to find the nearest unvisited cell.

↗

Act

Move one cell or remove one patch of dirt. The next observation begins the cycle again.

PEAS, assumptions, and limitations

Performance: reachable dirt cleaned, visited-cell coverage, and action count.

Environment: a static, discrete grid with dirt and obstacles.

Actuators: move up, right, down, left; clean; stop.

Sensors: current-cell dirt and adjacent occupancy.

Movement is deterministic; cleaning removes a patch in one action. Visited cells do not necessarily mean the whole real-world floor is clean. Obstacles can make dirt unreachable. BFS finds shortest paths to known targets, not an optimal whole-room cleaning tour. The simulator sees the complete room for rendering and evaluation; the agent receives local observations only.
